# StreamElements-win-counter
A simple stream widget that keeps track of wins/losses for OBS Twitch streaming on a game called Dead by Daylight for (Steam, PS5, Switch, and Xbox


Copy and paste each file in their designated location on StreamElements to get a working counter.

Colors and settings can be changed on SE without editing code.




Widget is neon themed (pink and purple) with moving stars and hearts to add details. once command is triggered (!death or !escape in Twitch chat) the counter is updated and a collection of skulls/stars or hearts/stars fly across the screen respectively.
